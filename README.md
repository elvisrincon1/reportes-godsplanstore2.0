# reportes-godsplanstore2.0

Este proyecto es una aplicación React creada con Create React App y utiliza Tailwind CSS para el diseño.

## Scripts disponibles

En el directorio del proyecto, puedes ejecutar:

### `npm start`

Ejecuta la aplicación en modo desarrollo.\
Abre [http://localhost:3000](http://localhost:3000) para verla en el navegador.

La página se recarga automáticamente cuando haces cambios.\
También puedes ver errores de lint en la consola.

### `npm run build`

Construye la aplicación para producción en la carpeta `build`.\
Optimiza el build para el mejor rendimiento.

### `npm test`

Ejecuta el corredor de pruebas en modo interactivo.

## Configuración

- Tailwind CSS está configurado en `tailwind.config.js`.
- PostCSS está configurado en `postcss.config.js`.

## Despliegue

Para desplegar la aplicación, ejecuta:

```bash
npm run build
```

Luego sirve la carpeta `build` con un servidor estático, por ejemplo:

```bash
npx serve -s build
```

## Notas

- Asegúrate de tener instaladas las dependencias con `npm install`.
- El proyecto utiliza React 19 y Tailwind CSS 4.
